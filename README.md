# Личный кабинет (Flask)

Сайт на Python: регистрация, вход, личный кабинет с именем, фамилией и балансом,
страница транзакций и отправка вопроса в нейросеть.

## Как запустить

Открой терминал в папке проекта (там, где лежит `pyproject.toml`).

**Через uv** (так настроено у учителя):

```
uv run src/sdfg/app.py
```

**Или обычным Python:**

```
pip install flask
python src/sdfg/app.py
```

Потом открой в браузере: http://127.0.0.1:5000

База данных `src/sdfg/database.db` создаётся сама при первом запуске.

## Как подключить нейросеть (GigaChat, бесплатно)

1. Зайди на https://developers.sber.ru, войди через Сбер ID.
2. Создай проект GigaChat API и скопируй «Ключ авторизации».
3. Открой `src/sdfg/ai.py` и вставь ключ в строку `API_KEY = ""`.

Без ключа сайт работает, только на вопрос нейросети покажет сообщение, что ключ не задан.
Другую нейросеть (DeepSeek, Ollama и т.д.) можно подключить в том же файле: `PROVIDER = "openai"`.

Не выкладывай ключ на GitHub в открытый репозиторий.

## Что где лежит

| Файл | Что делает |
|---|---|
| `src/sdfg/app.py` | Главный файл: адреса сайта и что на них происходит |
| `src/sdfg/database.py` | Работа с базой данных (пользователи и транзакции) |
| `src/sdfg/ai.py` | Запрос в нейросеть |
| `src/sdfg/templates/*.html` | Страницы: регистрация, вход, личный кабинет, транзакции |
| `src/sdfg/static/script.js` | Отправляет данные форм на сервер без перезагрузки страницы |
| `src/sdfg/static/style.css` | Оформление |
| `pyproject.toml`, `uv.lock` | Список библиотек проекта (нужен только Flask) |

## Адреса сайта

| Адрес | Что это |
|---|---|
| `/` | Регистрация |
| `/login` | Вход |
| `/lk` | Личный кабинет |
| `/transactions` | История и новые операции |
| `/logout` | Выход |
| `/user_register`, `/user_login`, `/add_transaction`, `/ask_ai` | Сюда `script.js` отправляет данные (POST, JSON) |
